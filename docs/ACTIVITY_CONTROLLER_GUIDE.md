## Architecture Overview

### Three-Layer Architecture (same pattern as User)

```
┌─────────────────────────────────────┐
│   ActivityController                │  ← HTTP Requests/Responses
│   (API Endpoints)                   │
└──────────────────┬──────────────────┘
                   │
                   ├─→ Validates input
                   └─→ Calls Service layer

┌──────────────────────────────────────┐
│   ActivityService Interface          │  ← Business Logic Contract
│   (Defines operations)               │
└──────────────────┬───────────────────┘
                   │
                   └─→ Implemented by ActivityServiceImpl

┌──────────────────────────────────────┐
│   ActivityServiceImpl                │  ← Business Logic Implementation
│   (In-Memory Operations)             │
└──────────────────────────────────────┘
```

### File Locations

| File | Location |
|------|----------|
| Controller | `controller/ActivityController.java` |
| Interface | `service/ActivityService.java` |
| Implementation | `service/impl/ActivityServiceImpl.java` |
| Model | `model/Activity.java` |

## Activity Model

```java
public class Activity {
    private Long id;
    private String name;
    private String description;
    private LocalDateTime createdAt;
}
```

| Field | Type | Set By |
|-------|------|--------|
| `id` | Long | Auto-generated by `AtomicLong` in service |
| `name` | String | Client (required) |
| `description` | String | Client (optional) |
| `createdAt` | LocalDateTime | Auto-set to `LocalDateTime.now()` in service |

## ActivityServiceImpl - Core Logic

### ID Counter: `AtomicLong`

```java
private final List<Activity> activities = new ArrayList<>();
private final AtomicLong idCounter = new AtomicLong(1);
```

| | ActivityServiceImpl | UserServiceImpl |
|--|---|---|
| ID Method | `AtomicLong` | `LocalDateTime` math |
| First ID | 1 | ~123456789 (malaki) |
| Next IDs | 2, 3, 4... | Recalculated each time |

`idCounter.getAndIncrement()` → returns current value then adds 1:
```
First call:  returns 1, counter becomes 2
Second call: returns 2, counter becomes 3
```

---

### Method 1: `createActivity(String name, String description)`

```java
@Override
public Activity createActivity(String name, String description) {
    Activity activity = new Activity(
            idCounter.getAndIncrement(), // Auto ID: 1, 2, 3...
            name.trim(),                 // Remove extra spaces
            description,                 // Can be null
            LocalDateTime.now()          // Current timestamp
    );
    activities.add(activity);
    return activity;
}
```

#### Walkthrough:

```
Input: name = "Lab Exercise", description = "Spring Boot"

STEP 1: Build Activity:
        id          = 1 (idCounter.getAndIncrement())
        name        = "Lab Exercise"
        description = "Spring Boot"
        createdAt   = 2026-04-11T10:30:00
        ↓
STEP 2: activities.add(activity)
        ↓
STEP 3: return activity

Output: Activity { id=1, name="Lab Exercise", ... }
```

---

### Method 2: `getAllActivities()`

```java
@Override
public List<Activity> getAllActivities() {
    return activities;
}
```

Simply returns the entire in-memory list.

---

### Method 3: `getActivityById(Long id)`

```java
@Override
public Activity getActivityById(Long id) {
    for (Activity activity : activities) {
        if (activity.getId().equals(id)) {
            return activity; // Found!
        }
    }
    return null; // Not found
}
```

#### Walkthrough:

```
Input: id = 2

List: [Activity(ID:1), Activity(ID:2), Activity(ID:3)]

Loop:
  ID=1 == 2? NO → continue
  ID=2 == 2? YES ✓ → return this activity

Output: Activity { id=2, ... }
```

---

### Method 4: `updateActivity(Long id, String name, String description)`

```java
@Override
public Activity updateActivity(Long id, String name, String description) {
    for (Activity activity : activities) {
        if (activity.getId().equals(id)) {
            activity.setName(name.trim());
            activity.setDescription(description);
            return activity; // Return updated activity
        }
    }
    return null; // Not found
}
```

> `id` and `createdAt` are NOT changed — only `name` and `description`.

---

### Method 5: `deleteActivity(Long id)`

```java
@Override
public boolean deleteActivity(Long id) {
    return activities.removeIf(activity -> activity.getId().equals(id));
}
```

`removeIf` → removes the element if condition is true, returns `true` if removed, `false` if nothing was removed.

#### Walkthrough:

```
Input: id = 2

List before: [Activity(ID:1), Activity(ID:2), Activity(ID:3)]

removeIf: finds ID=2 → removes it → returns true

List after: [Activity(ID:1), Activity(ID:3)]

Output: true
```

## ActivityController - Method Breakdown

### Setup

```java
private final ActivityService activityService = new ActivityServiceImpl();
```

Controller holds an instance of `ActivityServiceImpl` through the `ActivityService` interface.

---

### ActivityRequest (Input DTO)

```java
static class ActivityRequest {
    private String name;
    private String description;
}
```

**Why separate class from Activity?**
```
Client sends:      Service stores:
ActivityRequest →  Activity
  name               id          ← added by service
  description        name
                     description
                     createdAt   ← added by service
```

Client only sends `name` and `description`. Service handles `id` and `createdAt`.

---

### Method 1: `createActivity` — POST /activities

```java
@PostMapping
public ResponseEntity<?> createActivity(@RequestBody ActivityRequest request) {

    // STEP 1: Validate
    if (request.getName() == null || request.getName().trim().isEmpty()) {
        return ResponseEntity.badRequest().body("Name is required.");
    }

    // STEP 2: Delegate to service
    Activity activity = activityService.createActivity(request.getName(), request.getDescription());

    // STEP 3: Return 201 Created
    return ResponseEntity.status(HttpStatus.CREATED).body(activity);
}
```

#### Walkthrough Example 1 - Valid:

```
Input: POST /activities
Body: { "name": "Lab Exercise", "description": "Spring Boot" }

STEP 1: name = "Lab Exercise" → not null, not blank ✓
        ↓
STEP 2: activityService.createActivity("Lab Exercise", "Spring Boot")
        → Service builds Activity, saves to list, returns it
        ↓
STEP 3: Return HTTP 201 Created

Output: { "id": 1, "name": "Lab Exercise", "createdAt": "..." }
```

#### Walkthrough Example 2 - Missing Name:

```
Input: POST /activities
Body: { "description": "no name" }

STEP 1: name = null → INVALID!
Return: HTTP 400 Bad Request → "Name is required."
```

#### What It Returns:

| Scenario | HTTP Status | Body |
|----------|-------------|------|
| Valid | 201 Created | Activity object |
| Name missing/blank | 400 Bad Request | "Name is required." |

### Method 3: `getActivityById` — GET /activities/{id}

```java
@GetMapping("/{id}")
public ResponseEntity<?> getActivityById(@PathVariable Long id) {
    Activity activity = activityService.getActivityById(id);

    if (activity == null) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND)
                .body("Activity with ID " + id + " not found.");
    }
    return ResponseEntity.ok(activity);
}
```

#### Walkthrough:

```
Input: GET /activities/1

→ activityService.getActivityById(1)
→ Found? → Return 200 + Activity
→ Null?  → Return 404 + error message
```

#### What It Returns:

| Scenario | HTTP Status | Body |
|----------|-------------|------|
| Found | 200 OK | Activity object |
| Not found | 404 Not Found | Error message |

---

### Method 4: `updateActivity` — PUT /activities/{id}

```java
@PutMapping("/{id}")
public ResponseEntity<?> updateActivity(@PathVariable Long id,
                                        @RequestBody ActivityRequest request) {

    // STEP 1: Validate
    if (request.getName() == null || request.getName().trim().isEmpty()) {
        return ResponseEntity.badRequest().body("Name is required.");
    }

    // STEP 2: Delegate to service
    Activity activity = activityService.updateActivity(id, request.getName(), request.getDescription());

    // STEP 3: Check result
    if (activity == null) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND)
                .body("Activity with ID " + id + " not found.");
    }
    return ResponseEntity.ok(activity);
}
```

#### Walkthrough:

```
Input: PUT /activities/1
Body: { "name": "Updated Name", "description": "New desc" }

STEP 1: name = "Updated Name" → valid ✓
        ↓
STEP 2: activityService.updateActivity(1, "Updated Name", "New desc")
        → Service finds ID=1, updates name + description, returns activity
        ↓
STEP 3: activity != null → return HTTP 200 + updated activity

Before: { "id": 1, "name": "Lab Exercise", "createdAt": "..." }
After:  { "id": 1, "name": "Updated Name", "createdAt": "..." }
```

#### What It Returns:

| Scenario | HTTP Status | Body |
|----------|-------------|------|
| Updated successfully | 200 OK | Updated Activity |
| Name missing/blank | 400 Bad Request | "Name is required." |
| ID not found | 404 Not Found | Error message |

---

### Method 5: `deleteActivity` — DELETE /activities/{id}

```java
@DeleteMapping("/{id}")
public ResponseEntity<?> deleteActivity(@PathVariable Long id) {
    boolean removed = activityService.deleteActivity(id);

    if (!removed) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND)
                .body("Activity with ID " + id + " not found.");
    }
    return ResponseEntity.ok("Activity with ID " + id + " deleted successfully.");
}
```

#### Walkthrough:

```
Input: DELETE /activities/1

→ activityService.deleteActivity(1)
→ removed = true (found and deleted)
→ Return HTTP 200 + success message

Output: "Activity with ID 1 deleted successfully."
```

#### What It Returns:

| Scenario | HTTP Status | Body |
|----------|-------------|------|
| Deleted | 200 OK | Success message |
| Not found | 404 Not Found | Error message |

## Data Flow Diagrams

### Flow 1: Create Activity

```
POST /activities
Body: { "name": "Lab Exercise" }
        ↓
ActivityController.createActivity()
  ├─ Validate: name not null/blank ✓
  ├─ Call: activityService.createActivity("Lab Exercise", null)
  │         ↓
  │   ActivityServiceImpl.createActivity()
  │   ├─ id = idCounter.getAndIncrement() → 1
  │   ├─ createdAt = LocalDateTime.now()
  │   ├─ activities.add(activity)
  │   └─ return activity
  └─ Return ResponseEntity (HTTP 201 Created)
         ↓
Response: { "id": 1, "name": "Lab Exercise", "createdAt": "..." }
```

### Flow 2: Get by ID

```
GET /activities/2
        ↓
ActivityController.getActivityById(2)
  ├─ Call: activityService.getActivityById(2)
  │         ↓
  │   ActivityServiceImpl.getActivityById(2)
  │   ├─ Loop → find Activity with ID=2 ✓
  │   └─ return activity
  ├─ activity != null ✓
  └─ Return ResponseEntity (HTTP 200 OK)
         ↓
Response: { "id": 2, "name": "...", ... }
```

### Flow 3: Delete

```
DELETE /activities/1
        ↓
ActivityController.deleteActivity(1)
  ├─ Call: activityService.deleteActivity(1)
  │         ↓
  │   ActivityServiceImpl.deleteActivity(1)
  │   ├─ removeIf → finds ID=1 → removes it
  │   └─ return true
  ├─ removed = true ✓
  └─ Return ResponseEntity (HTTP 200 OK)
         ↓
Response: "Activity with ID 1 deleted successfully."
```

## Activity vs User Comparison

| | Activity | User (Student) |
|--|---|---|

| ID Generation | `AtomicLong` (1, 2, 3...) | `LocalDateTime` math |
| HTTP Responses | `ResponseEntity` with proper codes | Returns object directly |
| Not Found | Returns 404 | Returns `null` |
| Input Validation | Yes (checks name) | No validation |
