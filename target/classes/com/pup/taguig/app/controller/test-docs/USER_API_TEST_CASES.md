# User REST API — Test Cases

Base URL: `http://localhost:8080/user`

---

## 1. POST `/user/` — Add Student

**Request:**
```
POST http://localhost:8080/user/
Content-Type: application/json
```

**Body:**
```json
{
  "firstName": "Annie",
  "lastName": "Raquem",
  "midtermGrade": 88,
  "finalGrade": 92
}
```

**Expected Response:**
```json
{
  "id": 2026101234567,
  "firstName": "Annie",
  "lastName": "Raquem",
  "midtermGrade": 88,
  "finalGrade": 92
}
```
> `id` is auto-generated by the service based on the current date and time.

---

## 2. GET `/user/all` — Get All Students

**Request:**
```
GET http://localhost:8080/user/all
```

**Expected Response (after adding Annie via POST):**
```json
[
  { "id": 2026101234567, "firstName": "Annie", "lastName": "Raquem", "midtermGrade": 88, "finalGrade": 92 }
]
```

---

## 3. GET `/user/{id}` — Get Student by ID

> Use the `id` returned from the POST response.

**Request:**
```
GET http://localhost:8080/user/2026101234567
```

**Expected Response:**
```json
{
  "id": 2026101234567,
  "firstName": "Annie",
  "lastName": "Raquem",
  "midtermGrade": 88,
  "finalGrade": 92
}
```

**Edge Case — ID not found:**
```
GET http://localhost:8080/user/999
```
Expected: `null` or empty body

---

## 4. GET `/user/filter` — Search by Last Name + First Name

> Use the name of the student you added via POST.

**Request:**
```
GET http://localhost:8080/user/filter?lastName=Raquem&firstName=Annie
```

**Expected Response:**
```json
[
  { "id": 2026101234567, "firstName": "Annie", "lastName": "Raquem", "midtermGrade": 88, "finalGrade": 92 }
]
```

**Edge Case — No match:**
```
GET http://localhost:8080/user/filter?lastName=Santos&firstName=Jose
```
Expected: `[]`

---

## 5. DELETE `/user/{id}` — Delete Student

**Request:**
```
DELETE http://localhost:8080/user/2026101234567
```

**Expected Response:**
```
true
```

**Verify deletion:**
```
GET http://localhost:8080/user/all
```
Expected: Annie is no longer in the list.

---

## Full Flow (in order)

| Step | Method | URL | Notes |
|------|--------|-----|-------|
| 1 | POST | `/user/` | Add Annie Raquem, note the returned `id` |
| 2 | GET | `/user/all` | Confirm Annie is in the list |
| 3 | GET | `/user/{id}` | Get Annie using the returned ID |
| 4 | GET | `/user/filter?lastName=Raquem&firstName=Annie` | Search by full name |
| 5 | DELETE | `/user/{id}` | Delete Annie |
| 6 | GET | `/user/all` | Confirm Annie is gone |
